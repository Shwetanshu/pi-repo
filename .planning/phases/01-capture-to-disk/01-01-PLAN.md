stored in the current directory and still there when I come back.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell argv → `todo.js` | The item text is untrusted input: it is arbitrary bytes the user typed, can contain quotes, newlines, JSON metacharacters, and multi-megabyte payloads. |
